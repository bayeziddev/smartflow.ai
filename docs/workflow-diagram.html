Message → Reply, step by step

What happens between a customer's message arriving and an order landing in your dashboard
Channel
Customer messages you
WhatsApp, Telegram, Messenger or Email.
Channel handler
Inbound message received
WhatsApp: isolated worker. Telegram: webhook. Email: inbound parse.
Session
Look up or create session
Keyed by tenant + channel + customer handle.
AI Router
Resolve & decrypt key
AES-256-GCM decrypt in memory, for this call only.
Provider call
OpenAI → Groq → Gemini → Manus
Tries the requested provider, fails over through the rest on error.
On success
Parse intent + extract order
Model classifies intent, returns structured JSON in the same call.
On 401 / 429
Notify the tenant
401 also flips that key to invalid. 429 fails over immediately.
Reply
Answer sent to customer
Back through the same channel it arrived on.
Orders table
Order captured, idempotently
Only when intent = order_confirmation. Retries can't double-insert.
Delivery
Automated WhatsApp alert
To the tenant's own number, before the customer notices anything.
Dashboard
Ready for Excel export
One click, any time, from Orders in the dashboard.
